## 1. 핵심 기둥 세 개

| 기둥 | 내용 | 플레이어가 느껴야 할 것 |
|---|---|---|
| **생활형 용병업** | 콜, 차, 계약금, 탄값, 일당, 정산 | "이번 콜, 남는 장사였나?" |
| **모르는 채로 죽는 세계** | 사인을 알려주지 않음. 단서를 모아 스스로 알아냄 | "아, 그래서 죽었구나!" (깨달음) |
| **진화하는 몬스터** | 내 사냥 방식이 다음 세대를 만든다 | "저번에 불로 태웠더니 이놈들이 불에 안 타네…" |

세 기둥이 서로 맞물려야 한다.
- 탄값이 비싸니 → 무작정 쏘지 않고 관찰한다 → 관찰하니 진화가 보인다.
- 몰라서 죽으니 → 정보가 돈이 된다 → 기사식당에서 정보를 사고판다.
- 진화가 쌓이니 → 같은 번호 세계도 갈 때마다 다르다 → 정보가 낡는다 → 다시 조사해야 한다.

## 2. 기본 루프

```
[동네 일상] 배달·경호·이삿짐 (안전, 푼돈, 탄 안 씀)
     │  무전 "띠리릭─ 다세계 콜입니다"
     ▼
[콜 확인] 등급·위험도·자격·계약금 확인 → 수락 / 거절 / 다른 기사가 채감
     ▼
[준비] 인력사무소에서 용병 고용, 탄·필터·약품 구매, 차에 태우기
     ▼
[출동] 차로 현장(게이트)까지 운전. 라디오, 용병들 잡담
     ▼
[진입] N번 세계. 목표 → 중도금 지점 → 계속 갈지 철수할지 판단
     ▼
[귀환 or 전멸]
     ▼
[정산] 계약금 - 탄값 - 일당 - 수리비 - 보험료 = 순수익
     ▼
[기사식당] 정보 교환, 소문, 사인 분석, 다음 콜 대기
```

## 3. 80년대 한국 × 테일즈 프롬 더 루프

### 아트 방향
- 스톨렌하그 그림의 핵심은 **"평범한 일상 풍경 속에 아무렇지 않게 놓인 거대한 이질물"**이다.
- 한국판으로 바꾸면:
  - 논두렁 너머에 반쯤 묻힌 거대한 링 구조물(게이트), 동네 애들이 그 위에서 논다
  - 연탄 배달 리어카 옆을 지나가는 고장 난 6족 보행 기계
  - 아파트 공사장 크레인에 매달린 채 녹슨 정체불명의 구체
  - 버스정류장 표지판에 "제3관문 앞" 같은 정류장 이름
  - 비닐하우스, 슬레이트 지붕, 전봇대에 붙은 "심부름센터" 전단
- 색감: 바랜 필름, 겨울 오후의 비스듬한 빛, 안개 낀 새벽, 노을. 필름 그레인.
- **우리 세계는 따뜻하고 그리운 톤, 멀티버스는 같은 구도인데 차갑고 뒤틀린 톤.**

### "같은 동네, 다른 번호" (강력 추천)
- 각 번호 세계는 **우리 동네의 다른 가능성**이다. 지형과 건물 배치는 비슷한데 역사가 갈라졌다.
  - 3번: 가스 사고가 났던 세계. 동네 전체가 노란 안개에 잠김
  - 7번: 사람이 없어지고 식물만 남은 세계
  - 12번: 소리에 반응하는 생물이 지배하는 세계
- 장점
  - 익숙한 장소가 낯설어지는 공포 ("여기 우리 동네 문방구 자리인데…")
  - **맵 하나를 여러 번 재활용** → 개발비 절감, 프로토타입에 유리
  - 우리 세계 지리를 알면 다른 세계에서 길을 찾을 수 있음 → 일상 배달이 곧 지도 학습

### 시대 소품이 곧 게임 시스템
| 소품 | 게임에서 역할 |
|---|---|
| 무전기 / 카폰 | 콜 수신, 파티 명령, 세계 안 통신 (세계에 따라 잡음·두절) |
| 택시 미터기 | **사격 비용 실시간 표시 UI** (아래 4장) |
| 카세트 녹음기 | 사망 기록, 죽은 동료의 마지막 녹음 회수 → 사인 단서 |
| 기사식당 | 허브. 정보 교환, 용병 섭외, 소문 |
| 다방 | 의뢰인 미팅, 스토리 콜 시작점 |
| 인력사무소 / 용역 | AI 파티원 고용 |
| 보험 아줌마 | 생명보험·차량보험 판매. 전멸 대비 |
| 계약서 (계약금/중도금/잔금) | 콜 보상 구조 그 자체 |
| 신문·9시 뉴스 | 보도 통제된 세계관 정보, 세계 상태 변화 알림 |
| 공중전화 | 세이브 포인트? 콜센터 연락 |

### 세계관 뼈대 (초안)
- 정부 산하 "○○개발공사"(가칭)가 게이트를 관리. 공식적으로는 "지반 연구 시설".
- 실제 작업은 하청의 하청으로 민간 기사들에게 콜로 뿌린다. 사고가 나도 책임질 사람이 없는 구조.
- 보도 통제, 쉬쉬하는 분위기. 사람들은 다 알지만 말하지 않는다.
- 스토리 콜을 따라가면 공사의 실체, 첫 게이트 사고의 진실, 0번 세계(원본)의 정체에 다가간다.
- 반전 후보: **우리 세계도 누군가에게는 "N번 세계"다.** 다른 세계 기사들이 우리 세계로 콜을 받고 들어온다.

## 4. 돈 — 총알 하나하나가 비용

### 사격 미터기
- 화면 한쪽에 **택시 미터기 모양 UI**. 쏠 때마다 "딸깍" 하고 금액이 올라간다.
- 내 탄만이 아니라 **용병이 쏘는 탄도 내 돈**. 용병이 난사하면 미터기가 미친 듯이 돈다.
- 콜 진행 중 실시간 손익 표시: `계약금 확정 120,000 / 지출 47,300`
- 연출: 위기에서 "아끼면 죽고, 쏘면 적자" 딜레마가 숫자로 보인다.

### 탄 소비를 줄이는 수단 (소극적 플레이 방지용)
- 근접 무기 (삽, 쇠파이프, 각목) — 위험하지만 공짜
- 환경 이용 — 가스통, 전봇대, 물웅덩이 감전, 차로 들이받기
- 함정·미끼 — 몬스터 특성을 알면 싸게 처리 가능 → **정보가 곧 탄값 절약**
- 회피·은신 — 안 싸우는 게 제일 싸다
- 탄피 회수 / 재생탄 (싸지만 불발률)
- 탄 등급: 재생탄 < 일반탄 < 철갑탄 < 특수탄(세계별 약점탄)

### 계약 구조 (80년대 부동산 계약처럼)
- **계약금**: 콜 수락 시. 일반 콜은 받고 시작, 블루콜은 내가 내고 시작
- **중도금**: 세계 안 특정 지점(중도금 지점) 도달 시 확정
- **잔금**: 목표 달성 + 귀환 시
- **전멸 시 중도금까지만 지급**
  → 중도금 지점이 사실상 체크포인트. "찍고 빠질까, 잔금까지 갈까?" 하는 판단이 생긴다.
  → 콜마다 중도금 비율이 다름. 중도금이 높은 콜 = 의뢰인이 위험을 알고 있다는 뜻 (복선)

### 지출 항목
- 탄약, 방독면 필터, 약품, 연료
- 용병 일당 (출동 기준), 위험수당 (해골콜), 사망 시 위로금
- 차량 수리, 견인비
- 보험료 (들면 전멸 손실 일부 보전)
- 정보 구매비

## 5. 콜 시스템

### 콜 등급
| 표식 | 이름 | 특징 |
|---|---|---|
| (없음) | 일반 콜 | 동네 안 일, 혹은 얕은 세계 단기 작업 |
| ☠ | 해골 콜 | 위험. 보상 큼. 공사도 사망을 예상하고 있음 |
| ★ | 에픽 콜 | 드물게 뜸. 세계의 큰 변화, 대형 개체, 특수 보상 |
| 🔵 | 블루 콜 | 돈을 내고 받는 콜. 투자형. 정보값·입장료 성격 |
| 📖 | 스토리 콜 | 메인 이야기. 특정 의뢰인·장소에서만 받음 |

### 콜 자격 (면허)
- 80년대 개인택시 면허처럼 **"무사고 경력"**이 자격이 된다.
  - 전멸 = 사고 기록. 사고가 쌓이면 상위 콜이 안 들어옴
  - 연속 무사고 n건 → 해골 콜 자격, 에픽 콜 자격
- 기타 자격: 보유 차량 등급, 협회 회원증, 특정 세계 출입증, 동반 용병 수
- 일부러 무자격으로 몰래 받는 "뒷콜"도 가능? (위험, 보상 큼, 걸리면 면허 정지)

### 콜 경쟁 (솔플 버전 PvPvE)
- NPC 경쟁 기사들이 같은 콜을 노린다. 무전에서 먼저 "제가 받겠습니다" 해야 함
- 해골 콜은 다른 업체 AI 팀이 같은 세계에 동시에 들어올 수 있음
  - 협력, 무시, 전리품 다툼, 배신 가능
  - **나중에 이 자리를 실제 플레이어로 바꾸면 PvP가 된다** → 솔플 단계에서 구조를 미리 만들어 두기

### 일상 일거리 (콜 대기 중)
- 배달: 연탄, 우유, 약, 짜장면, 수상한 소포
- 경호: 다방 사장님 수금길, 선거 유세(!)
- 이삿짐, 사람 태워주기
- 역할: 안전한 수입, 동네 지리 학습(=다른 세계 길찾기), 소문 수집, 스토리 떡밥

## 6. 멀티버스 — 번호별 세계

### 세계 하나를 정의하는 요소
- **환경 규칙**: 공기(독가스), 빛, 소리, 중력, 시간 흐름, 무전 상태
- **생태계**: 서식 몬스터 종, 먹이사슬, 개체 수
- **세대 카운터**: 진화가 몇 세대 진행됐는지
- **위험도**: 공사가 매긴 등급 (틀릴 수 있음!)

### 세계 예시
| 번호 | 이름(가칭) | 규칙 | 특징 |
|---|---|---|---|
| 3 | 노란 안개 | 독가스. 필터 소모 | 시야 짧음. 가스 농도 지도가 핵심 정보 |
| 7 | 푸른 동네 | 식물이 건물을 삼킴 | 식물형 몬스터. 불이 잘 먹히지만 산불 위험 |
| 12 | 조용한 마을 | 소리에 반응 | **총소리 자체가 위험**. 탄값 + 어그로 이중 비용 |
| 19 | 밤만 있는 곳 | 해가 안 뜸 | 빛 = 어그로. 조명탄이 무기이자 자살 |
| 24 | 거꾸로 흐르는 | 시간 이상 | 죽은 동료가 잠깐 다시 나타남(?) |
| 31 | 무전 두절 | 통신 불가 | 용병 명령 불가. 미리 지시한 대로만 움직임 |

### 진입 규칙 아이디어
- 게이트마다 열리는 번호가 날마다 바뀜 (콜이 그날의 번호를 알려줌)
- 차를 끌고 들어갈 수 있는 게이트 / 도보만 되는 게이트
- 세계 안에 오래 있을수록 "오염도"가 쌓임 → 귀환 후 병원비

## 7. 왜 죽는지도 모르는 세계

### 원칙
- **사인을 바로 알려주지 않는다.** 정산서에 "사인 불명"이라고만 찍힌다.
- 대신 **모든 죽음은 사후에 재구성 가능해야 한다.** (공정성 원칙)
  - 단서가 없는 죽음은 좌절, 단서가 있는 죽음은 미스터리.

### 단서 수단
- **카세트 녹음**: 동료가 죽기 직전 무전/녹음. 회수하면 들을 수 있음 ("…뭐야 이 냄새… 다들 숨 참…")
- **시신·장비 회수**: 다음 출동 때 이전 팀의 시신을 찾아 조사. 장비 상태, 상처 모양
- **환경 흔적**: 그을음, 녹은 자국, 발자국, 시체 배치
- **사인 도감**: 밝혀낸 사인이 도감에 채워지고, 채우면 대응법(장비·행동) 해금
  - 예: "3번 세계 / 사인 #04 / 지하 가스 고임 — 계단 아래로 내려가지 말 것"

### 정보 교환 (솔플 버전)
- 기사식당에서 NPC 기사들과 정보를 주고받는다
  - 내 정보를 주면 상대 정보를 받음. 정보끼리 물물교환
  - 정보에 **신뢰도**가 있음. 헛소문, 낡은 정보(진화로 이미 바뀜), 일부러 틀린 정보(경쟁 기사의 함정)
- 게시판 쪽지: "12번 세계 문방구 자리, 셔터 내린 가게 열지 말 것 — 김 기사"
- 정보를 공사나 다른 기사에게 **팔 수도 있음** → 조사 자체가 수입원
- 나중에 멀티로 확장하면 다른 플레이어의 쪽지·녹음 테이프가 비동기로 들어오는 구조

### 죽음이 일상인 분위기 연출
- 기사식당 벽에 순직 기사 사진. 아는 얼굴이 늘어난다
- 용병 인력사무소에 "결원 보충" 공고
- 동네 사람들이 담담하게 "이번엔 누가 갔대?" 하는 대사

## 8. 몬스터 AI — 유전과 진화

### 구조 제안
- **행동 블록**(패턴)은 디자이너가 만든다: 돌진, 매복, 포위, 도망, 시체 먹기, 소리 추적, 땅파기, 위장…
- **유전자**는 숫자 묶음: 크기, 속도, 장갑, 감각(시각/청각/후각), 공격성, 무리 성향, 학습 성향, 내성(불/전기/가스), 약점 위치
- 유전자가 어떤 행동 블록을 얼마나 자주 쓸지 결정한다
  → **패턴은 읽을 수 있고(공정), 조합은 매번 달라진다(신선)**
- 머신러닝이 아니라 **진화 시뮬레이션**이라 디자이너가 통제하기 쉽고, 플레이어도 원리를 이해할 수 있다

### 선택압 세 가지
| 이름 | 무엇이 | 예 |
|---|---|---|
| 자연선택 | 세계 환경 | 가스 세계 → 폐 없는 개체만 남음 |
| 적자생존 | 종끼리 경쟁·먹이사슬 | 큰 놈이 작은 놈을 잡아먹어 덩치가 커짐 |
| **인간선택** | **플레이어의 사냥 방식** | 불로만 잡았더니 내열 개체가 번성 |

### 사냥 결과 반영 (핵심 재미)
- 플레이어와 마주쳤다가 **살아남은 개체**가 번식 확률이 높다
- 내가 죽인 방식이 기록되고, 그 방식에 강한 개체가 다음 세대에 늘어난다
  - 머리만 쏘면 → 머리 장갑 두꺼운 개체
  - 낮에만 사냥하면 → 야행성 개체
  - 소리 내며 쫓으면 → 소리 들리면 숨는 개체
- 반대로 **일부러 길들이기**도 가능
  - 공격적인 개체만 골라 잡으면 순한 세계가 된다 → 안전한 "농장 세계"
  - 의뢰인이 원하는 특성을 가진 개체를 포획하는 **품종 개량 콜**
- 트레이드오프로 폭주 방지: 장갑↑ = 속도↓, 감각↑ = 수명↓, 세계별 개체수 상한

### 진화를 보이게 하기
- 세대 리포트 (공사 보고서 형식): "3번 세계 제14세대 — 평균 장갑 +12%, 야간 활동 개체 비율 상승"
- 개체 표식: 흉터, 부러진 뿔, 내 탄이 박힌 채 살아남은 놈 → **"저번에 놓친 그놈"**
- 이름 붙은 개체가 우두머리로 성장 → 에픽 콜 대상

## 9. AI 파티원 (고용 용병)

### 고용
- 인력사무소, 기사식당 단골, 소개, 스토리로 합류
- 일당제 + 위험수당. 오래 데리고 다니면 정이 붙고(친밀도) 일당 협상 가능
- **차 좌석 수 = 파티 정원**
  - 포니 택시 4인 / 봉고 승합 8인 / 화물 트럭(짐칸) 다수
  - 트렁크 = 전리품 용량 → 차량 업그레이드가 곧 성장

### 성격과 특성
- 탄 소비 성향: 난사형(전투력↑, 돈↓) / 짠돌이형 / 근접 선호
- 겁 많음, 무모함, 말 많음, 도둑 손(전리품 슬쩍)
- 특기: 운전, 정비, 의무, 조사(단서 발견률↑), 무전, 폭파
- 세계별 트라우마: 3번 세계에서 동료를 잃은 용병은 3번 세계 콜을 거부할 수도
- 부상·사망 영구. 죽으면 유족 위로금. 기사식당 벽에 사진

### 명령 (무전 명령, 단순하게)
- 따라와 / 대기 / 엄호 / 진격 / 철수 / 쏘지 마(탄 아끼기)
- "쏘지 마" 명령이 이 게임의 특색이 될 수 있음
- 무전 두절 세계에서는 출발 전 지시한 대로만 움직임 → 브리핑이 중요해짐

### 차 안에서
- 이동 중 용병끼리 잡담 → 성격 표현, 소문, 세계 정보
- 라디오: 80년대풍 오리지널 가요, 뉴스(세계관 정보), 날씨(=게이트 상태)

## 10. 차량

- 이동 수단 + 이동 거점 + 인벤토리 + 탈출 수단
- 연료비, 고장, 타이어 펑크, 정비 기술
- 세계 안까지 몰고 들어가면: 빠른 이동, 엄호물, 들이받기, 대신 소음·파손 위험
- 게이트 앞에 세워 두면: 귀환 지점. 몬스터가 차를 망가뜨리면 걸어서 탈출해야 함
- 튜닝: 방탄판, 서치라이트, 가스 차단 실내, 견인 고리, 루프랙
- 콜 수신 성능 = 무전기 등급 (좋은 무전기 = 더 먼 곳, 더 좋은 콜)

## 11. 솔플 프로토타입 범위 제안

### 1차 목표: "콜 하나를 받아서 정산까지"
1. TPS 이동·사격 + 사격 미터기 UI
2. 동네 맵 하나 (작게) + 차 운전 + 무전 콜 수신
3. 세계 하나: **3번 노란 안개** (같은 동네 맵 재활용 + 안개·가스 규칙)
4. 몬스터 2종 + 간단한 진화(유전자 3~4개, 세대 교체는 콜 단위)
5. 용병 2명 고용, 명령 4개 (따라와/대기/엄호/쏘지 마)
6. 계약금 / 중도금 / 잔금 + 정산 화면
7. 사망 시 카세트 녹음 하나 남기기

### 프로토타입으로 확인할 질문
- 사격 미터기 때문에 **긴장감**이 생기나, 아니면 그냥 **짜증**이 나나?
- 운전 구간이 즐거운가, 지루한가? (지루하면 빠른 이동 or 이동 중 이벤트)
- 진화가 3~5회 출동 안에 **체감**되나?
- "모르고 죽음 → 단서 → 깨달음" 순환이 실제로 일어나나?
- AI 동료가 짐이 되나, 든든하나?
