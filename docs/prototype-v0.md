# 프로토타입 v0 — 그레이박스 수직 슬라이스

> 목표: brainstorm-02 7장의 1차 범위 중 **"콜 하나를 받아서 정산까지 (전멸하면 뷰로 회수까지)"**를 도형만으로 돌려 본다.
> 아트·사운드·애니메이션 없음. 재미 검증용.

---

## 실행

- 엔진: **Unity 6.3 LTS (6000.3.22f1)**, URP, Input System
- `Assets/_Project/Scenes/Main.unity`를 열고 Play
- 씬에는 카메라와 `GameManager`만 있다. 맵·캐릭터·UI는 전부 코드로 짓는다
- 세이브: `%USERPROFILE%\AppData\LocalLow\DefaultCompany\manyworld\manyworld_save.json` (기사식당 화면의 "세이브 초기화"로 지움)

## 조작

| 키 | 동작 |
|---|---|
| WASD / Shift | 이동 / 달리기 (발소리가 커진다) |
| 마우스 / 우클릭 | 시점 / 조준 (탄 퍼짐 감소) |
| 좌클릭 | 카빈 사격 — **발당 ₩330, 미터기에 바로 찍힌다** |
| R / V | 재장전 / 쇠파이프 근접 (공짜, 위험) |
| E (길게) | 목표 회수, 동료 깨우기, 게이트에서 귀환·철수, 뒤집힌 티코 밀어 세우기 |
| E (티코 옆 / 안) | 티코 타기 / 내리기. 은주가 15m 안에 있으면 같이 탄다. 차 안에서는 WASD 운전, Space 핸드브레이크 |
| L (차 안) | 전조등. 영원한 밤 세계에선 빛이 몬스터를 부른다 |
| F | 손전등 (영원한 밤 세계에서 빛 = 어그로) |
| 1 2 3 4 | 은주 명령: 따라와 / 대기 / 엄호 / 쏘지 마 |
| 기절 중 1 2 | 무전: 깨워 줘 / 먼저 가 (25% 확률로 끊긴다) |
| Esc | 일시 정지 (볼륨 조절) |
| M | 소리 끄기/켜기 |

운전 (출동 구간)

| 키 | 동작 |
|---|---|

| Esc | 콜 취소하고 기사식당으로 |

## 아트 (임시 — everret-unity에서 가져옴)

최종 아트 방향(테일즈 프롬 더 루프풍, 80년대 한국)과는 다른 **임시 아트**다. 몬스터는 가져오지 않았다 (이 프로젝트에서 따로 만든다).

| 에셋 | 쓰는 곳 | 출처 |
|---|---|---|
| Synty POLYGON Town | 집 11종 | everret `ExternalAssets/SyntyPackages` 원본 패키지 |
| Synty POLYGON City | 가게·낡은 사무실, 주차 차량, 소화전·쓰레기통·벤치, 티코(소형차) | 〃 |
| Tripo 동료 모델 (Mixamo 뼈대) | 기사 = 01 도현, 은주 = 02 루나 | everret `ExternalAssets/TripoCompanions/rigged` |
| Mixamo Pro Rifle Pack | 대기·조준·걷기·달리기·쓰러짐 | everret `ExternalAssets/Mixamo` |
| 118 sprite effects bundle | 총구 화염, 피, 연기 (3개 폴더만) | Asset Store 캐시 원본 패키지 |
| Kronnect Volumetric Fog & Mist 2 | 세계별 볼류메트릭 안개 (독가스 노란 저지대 안개, 밤안개 + 손전등 빛줄기) | Asset Store 캐시 원본 패키지 |

**레포에는 올리지 않는다.** 유료·외부 에셋이라 `.gitignore`로 뺐다 (`Assets/Synty`, `Assets/ThirdParty`, `Assets/118 sprite effects bundle`, `Assets/VolumetricFog2`).
코드는 에셋이 없으면 그레이박스와 거리 안개로 그린다. 볼류메트릭 안개는 리플렉션으로 붙어서 패키지가 없어도 컴파일된다.

주의: URP 렌더러(`Assets/Settings/PC_Renderer.asset`)에 Volumetric Fog 렌더 피처가 등록돼 있어서, 패키지가 없는 PC에서는 "Missing script" 경고가 뜬다. 렌더링에는 영향이 없다.

새 PC에서 아트를 켜려면: 위 패키지들을 가져오고, Tripo 모델 2개와 Mixamo 클립을 `Assets/ThirdParty/Characters`, `Assets/ThirdParty/Mixamo`에 넣은 뒤 메뉴 **Manyworld > Art > Setup All**.
(`Assets/_Project/Resources/ArtCatalog.asset`이 이 에셋들을 가리킨다. 없으면 비어 있는 채로 동작한다.)

## 코드 구조

```
Assets/_Project/
  Scripts/            (Manyworld.asmdef)
    Core/     GameManager(모드 전환) SaveData Graybox Sfx Health HitZone Noise Tracer Billboard AutoShot
    World/    WorldGenerator(번호→세계) TownBuilder(동네+변조+네비메시)
    Player/   PlayerController PlayerCamera PlayerWeapon
    AI/       Monster Genome Evolution Companion
    Mission/  MissionController(콜 진행) CallContract(계약·장부·정산) DeathCauses(사인·사건·도감) GasPocket
    Drive/    TicoCar(아케이드 차량) DriveSession(출동 운전)
    UI/       IMGUI 화면: HubScreen CaseBoard(사인 분석·카세트·도감) MissionHUD SettlementScreen BureauScreen
  Resources/Audio/      효과음 WAV (Agent Audio 생성 → 트리밍·정규화·루프 크로스페이드)
  Resources/Materials/  그레이박스 베이스 머티리얼 (빌드에서 URP 셰이더 변형이 빠지지 않게)
  Editor/     ProjectSetup (Main 씬, 베이스 머티리얼) BuildTools (Windows 빌드)
  Tests/PlayMode/  CallLoopTests(콜 루프), FeatureTests(운전·사건·도감·가스·사운드), VisualCaptureTests(렌더 캡처)
```

테스트 실행 (Unity 에디터를 닫은 상태에서):

```
Unity.exe -batchmode -projectPath . -runTests -testPlatform PlayMode -testResults results.xml
```

빌드 후 주요 화면 자동 스크린샷 (개발용):

```
Builds/Windows/Manyworld.exe -screen-fullscreen 0 -mwshots <저장 폴더>
```
