> 확정: 2인승 티코 / 기절 + 회수 / 1987~88년 / 절차 생성 세계 번호
> 결정 목록은 [decisions.md](decisions.md)에 있다.

## 1. 티코 — 2인승으로 시작하기

### 시대 문제
- 티코는 실제로 **1991년**에 나왔다. 1987년과 4년 어긋난다.
- 어긋남을 숨기지 말고 **세계관으로 쓰자.**
  - "공사가 다른 번호 세계에서 들여온 설계도로 먼저 찍어 낸 국민차"
  - 동네 사람들은 그냥 "공사 차", "깡통차"라고 부른다
  - 플레이어가 처음으로 마주치는 **"이 세계가 우리가 아는 1987년과 조금 다르다"는 신호**가 된다
- 이 방식이면 다른 시대 소품(삐삐, 워크맨 신모델 등)도 같은 논리로 조금씩 앞당겨 쓸 수 있다. 단, 남발하지 않기.

### 2인승이 게임을 어떻게 바꾸나
- **동료가 단 한 명** → 누구를 태우느냐가 콜마다 가장 큰 결정이 된다
- 기절 시스템(2장)과 맞물려서 **"내가 쓰러지면 이 사람 혼자 끝내야 한다"**는 긴장이 생긴다
- 둘이 다니니 **버디물** 분위기. 차 안 대화가 깊어진다
- 트렁크가 작아서 전리품을 거의 못 싣는다 → 초반엔 계약금 위주 수입, 전리품은 차를 바꾼 뒤의 재미

### 티코만의 장단점
| 장점 | 단점 |
|---|---|
| 싸다 (할부 부담 적음) | 덩치 큰 몬스터에게 밀리고 뒤집힌다 |
| 연비가 좋다 → 연료비 거의 없음 | 트렁크가 작다 |
| 골목·산길 진입 가능 | 방탄판을 달면 너무 무거워진다 |
| 가벼워서 사람 둘이 밀어서 뒤집힌 걸 세울 수 있다 | 엄호물로 쓰기엔 얇다 |

### 차량 성장 경로 (초안)
```
티코 (2인) → 포니 (4인) → 봉고 (8인) → 화물 트럭 (짐칸 다수)
        └→ 티코 개조 (2인 유지, 성능 강화) — 끝까지 티코로 버티는 길도 남겨 두기
```

### 첫 동료
- 첫 동료는 **고정 스토리 캐릭터** 추천. 인력사무소에서 뽑는 일반 용병이 아니라 처음부터 함께하는 사람
  - 예: 공사에서 잘린 전직 측량기사, 말이 많고 겁도 많지만 지도는 기막히게 읽는다
  - 이 사람이 플레이어를 기절에서 몇 번 끌어내 주면서 관계가 생긴다
- 이후 일반 용병은 "두 번째 좌석의 주인"을 놓고 첫 동료와 경쟁하는 구도

## 2. 기절 시스템

### 기본 규칙
- 플레이어도 동료도 **체력이 0이 되면 기절**한다. 영구 사망은 없다
- 플레이어가 기절해도 **동료가 목표를 달성하고 귀환하면 콜 성공**
- 두 사람 모두 기절하면 **전멸** → 중도금까지만 받고, 회수반(3장)이 데려온다

### 플레이어가 기절해 있는 동안
- 화면은 흐려진 채 **소리 위주**로 바뀐다. 무전 잡음, 동료 목소리, 멀리서 나는 발소리
- 할 수 있는 것: **무전 명령만** (따라와 대신 "먼저 가", "나 두고 철수해", "버텨" 등 기절 전용 명령)
  - 의식이 오락가락해서 명령이 가끔 끊겨 전달됨
- 동료의 선택지
  - **깨운다**: 각성제·응급 처치. 시간이 걸리고 그동안 무방비. 깨어나면 체력 낮음
  - **업고 간다**: 이동 느려짐, 동료 사격 불가. 차까지 데려가면 귀환 처리
  - **두고 간다**: 혼자 목표 진행. 대신 내 몸이 그 자리에 남는다
- **쓰러진 몸은 세계 안에 남는다**
  - 몬스터가 몸을 끌고 가거나, 먹이로 쌓아 두거나, 둥지로 옮길 수 있다 (진화로 생기는 행동)
  - 끌려간 몸은 회수 난도가 오른다 → 회수비 상승
- 동료 성격에 따라 반응이 다르다: 겁쟁이는 바로 도망, 의리파는 끝까지 업고 감, 짠돌이는 각성제를 아끼려 함

### 기절의 대가 (영구 사망이 없는 대신)
- 병원비, 회수비
- **기억 손실**: 기절 직전 몇 분이 기억나지 않는다 (아래 참고)
- 장비 손실: 쓰러진 자리에 두고 온 무기, 회수 과정에서 사라진 물건
- 콜 기록: 기절 횟수가 무사고 경력에 영향 (전멸만 사고로 칠지, 기절도 감점할지는 밸런스로)
- 후유증: 같은 세계에서 여러 번 쓰러지면 그 세계 공포증 (조준 흔들림, 환청 등)

### 기억 손실 = "왜 죽는지도 모르는 세계"
- 이게 핵심 연결점이다. **기절하면 직전 기억이 날아가서, 왜 쓰러졌는지 모른다.**
- 그래서 단서를 모아야 한다
  - 깨어났을 때 몸에 남은 흔적: 화상, 이상한 냄새, 피부 변색, 주머니에 든 낯선 물건
  - 동료의 증언 (동료도 같이 쓰러졌으면 증언 없음)
  - 카세트 녹음기 (켜 두었으면 마지막 몇 분이 녹음되어 있다)
  - 회수반이 남긴 회수 보고서 (어디서, 어떤 상태로 발견했는지)
- 사인을 밝혀내면 **사인 도감**에 기록된다 → "사인 불명"이 "3번 세계 / 지하 가스 고임"으로 바뀌는 순간이 이 게임의 쾌감

## 3. 회수반 — 매니월드의 그 세력

### 컨셉 후보
| 후보 | 분위기 | 한 줄 |
|---|---|---|
| **넝마주이** (추천) | 80년대 넝마주이를 비튼 것. 망태기를 메고 세계 사이를 다닌다 | "쓸 만한 건 다 주워 갑니다. 사람도요." |
| 청소부 | 주황 작업복, 무표정, 말이 없다 | 공사와 연결된 듯 아닌 듯 |
| 상여꾼 | 요령 소리와 함께 나타난다. 죽음의 냄새 | 공포 쪽으로 강하게 |

**넝마주이 추천 이유**
- 시대감이 확실하다 (실제 80년대에 사회문제였던 존재)
- "쓸모 있는 걸 주워 간다"는 설정이 **장비 손실**과 자연스럽게 이어진다
- 사회에서 보이지 않는 사람들이 세계 사이를 가장 잘 안다는 아이러니 → 스토리 떡밥

### 회수 규칙
- 전멸하면 자동 회수. 다음 날 아침 기사식당 앞 평상이나 티코 운전석에서 깨어난다
- **회수비**: 중도금에서 떼어 간다. 모자라면 빚
- **수수료로 물건을 가져간다**: 무작위 장비 하나, 혹은 가장 비싼 것 하나
  - 가져간 물건은 나중에 **넝마주이 고물상**에서 되살 수 있다 (비싸게)
  - 가끔 **다른 세계에서 발견**된다 → 넝마주이가 세계 사이를 오간다는 증거
- 회수 보고서: 발견 위치, 상태, "주변에 ○○ 흔적" 같은 짧은 메모 → 사인 단서

### 정체 떡밥 (스토리 콜용)
- 넝마주이는 왜 공짜에 가깝게 사람을 데려다 주나?
- 그들은 어느 번호 세계 출신인가? 혹시 번호가 없는 세계?
- 회수될 때마다 아주 조금씩 **무언가가 바뀌어 돌아온다면?** (기억, 몸, 혹은 "같은 나"가 맞나)
  - 너무 일찍 밝히지 말고, 플레이어가 수십 번 회수된 뒤에야 의심하게 만들기

### 회수반과의 관계
- 넝마주이에게 잘해 주면 (고물 팔아 주기, 부탁 들어주기) 회수 수수료가 줄어든다
- 반대로 공사 편에 서면 넝마주이가 회수를 늦게 온다 → 몸이 더 오래 세계에 방치됨
- 넝마주이 전용 콜: "고철 주워 와라", "이 사람을 찾아라" (실종자 회수 콜)

### 동료가 회수 안 되는 경우?
- 기본은 동료도 회수된다
- 다만 **실종** 상태를 열어 두는 것도 고려: 몬스터가 아주 깊이 끌고 가서 넝마주이도 못 찾은 경우
  - 실종된 동료를 찾으러 가는 **구출 콜**이 생긴다
  - 영구 사망은 없지만 "잃어버릴 수 있다"는 긴장은 남는다
  - 결정 필요 (6장)

## 4. 절차 생성 세계 — 번호가 곧 시드

### 대원칙
- **같은 번호는 언제나 같은 기본 세계다.** (번호 = 시드)
  - 그래야 "12번 세계에선 총 쏘지 마" 같은 정보가 의미를 가진다
  - 나중에 멀티로 가면 플레이어끼리 같은 번호의 정보를 공유할 수 있다
- **기본 규칙은 고정, 생태계는 변한다.**
  - 환경 규칙(가스, 소리, 빛…)은 번호가 정한다 → 한번 밝히면 계속 유효
  - 몬스터 개체군은 진화한다 → 생태 정보는 시간이 지나면 낡는다
  - 이 이중 구조가 "정보 교환은 가치 있지만 영원하지 않다"를 만든다

### 번호 체계
- 형식: `제 ○○○ 번 세계` (공사 문서 표기). 예: 제3번, 제47번, 제512번
- **번호가 클수록 우리 세계에서 멀다** (갈라진 시점이 오래되었다)
  - 작은 번호: 동네 모습이 거의 같다. 규칙 1개, 약함
  - 중간 번호: 건물 배치는 같은데 풍경이 많이 다르다. 규칙 2개
  - 큰 번호: 동네 흔적만 남았다. 규칙 3개 이상, 강함
- 콜 등급과 연결: 해골 콜은 주로 큰 번호, 하지만 작은 번호에도 가끔 함정 같은 세계가 있다
- 0번, 1번은 특별 취급 (스토리용으로 비워 두기)

### 생성 레이어
번호(시드)에서 아래 레이어를 순서대로 뽑는다.

```
번호(시드)
 ├─ ① 거리(번호 크기) → 변형 강도, 규칙 개수, 기본 위험도
 ├─ ② 갈라진 사건    → 세계의 "역사" 한 줄 (가스 사고, 홍수, 인구 소멸, 정전…)
 ├─ ③ 환경 규칙       → 규칙 풀에서 1~N개, 각각 강도
 ├─ ④ 지형 변조       → 동네 기본 맵 위에 덮는 변형 레이어
 ├─ ⑤ 생태계 초기값   → 서식 종, 개체 수, 초기 유전자 분포
 └─ ⑥ 콜 성향         → 이 세계에서 주로 뜨는 콜 종류
```

**② 갈라진 사건이 나머지를 끌고 간다.** 무작위 규칙을 그냥 섞으면 세계가 따로 논다. 사건 하나를 먼저 뽑고, 그 사건과 어울리는 규칙·지형·생태에 가중치를 주면 세계마다 이야기가 생긴다.
- 예: "1979년 화학공장 폭발" → 독가스 규칙 가중치↑, 지형에 녹슨 탱크·폐허↑, 폐 없는 생물↑

### 환경 규칙 풀 (초안)
| 분류 | 규칙 | 플레이에 미치는 영향 | 대응 소모품 |
|---|---|---|---|
| 대기 | 독가스 | 체력 지속 감소, 저지대에 고임 | 방독면 필터 |
| 대기 | 산소 부족 | 달리기 제한 | 산소통 |
| 빛 | 영원한 밤 | 시야 짧음, 빛이 어그로 | 손전등 배터리, 조명탄 |
| 빛 | 강한 빛 | 눈부심, 그림자 속 생물 | 선글라스(!), 차양 |
| 소리 | 소리 반응 | 총소리·발소리가 어그로 | 소음기, 근접 무기 |
| 소리 | 소리 먹힘 | 동료 무전·발소리가 안 들림 | 수신호 |
| 통신 | 무전 두절 | 동료 명령 불가 | 사전 브리핑 |
| 통신 | 무전 혼선 | 다른 세계 무전이 섞임 (단서 or 거짓 정보) | — |
| 시간 | 느린 시간 | 바깥 세계보다 시간이 빨리 흐름 → 일당 증가 | — |
| 물 | 침수 | 저지대 물에 잠김, 수중 생물 | 장화, 고무보트 |
| 중력 | 약한 중력 | 높이 뛰고, 탄도가 휜다 | — |
| 생물 | 포자 | 오래 머물면 감염 (귀환 후 치료비) | 마스크, 해독제 |

- 규칙끼리 **충돌 금지 목록**을 둔다 (예: 침수 + 산소 부족은 너무 가혹 → 동시 생성 확률 낮춤)
- **조합에서 재미가 나온다**: 소리 반응 + 영원한 밤 = 보이지도 않고 쏘지도 못함 → 해골 콜 단골

### 지형 변조 레이어
동네 기본 맵 하나 위에 덮어씌운다.
- 침수 (수위 단계별), 붕괴 (구역 무작위), 식생 (덩굴·숲), 안개 (농도 지도), 결정화, 거대 구조물 박힘, 동네 일부가 다른 세계 지형으로 바뀜(패치)
- 같은 문방구 자리라도 번호마다 다르게 보인다 → "같은 동네, 다른 번호" 유지
- 프로토타입은 **기본 맵 1개 + 변조 레이어 3종(안개, 침수, 붕괴)**으로 시작

### 세계 정보 공개 방식
- 처음 들어가는 번호는 콜 정보에 **"공사 추정치"**만 뜬다. 틀릴 수 있다
  - 예: `제47번 / 공사 추정 위험도 2 / 규칙: 대기 이상(?)`
- 조사로 밝혀낸 것만 내 **세계 수첩**에 확정 기록된다
- 기사식당에서 남의 수첩 내용을 사고팔 수 있다 (신뢰도 표시)
- 세계 수첩 = 이 게임의 도감. 번호가 무한하니 수집 목표는 "많이 밝히기"보다 **"자주 가는 세계를 깊이 알기"**로

### 진화 상태 저장
- 플레이어가 한 번이라도 간 번호만 진화 상태를 저장한다 (안 간 번호는 시드에서 초기값으로 생성)
- 세대 교체는 **콜 단위 + 경과 일수**로. 오래 안 가면 그만큼 진화가 진행되어 있다
  - "석 달 만에 47번에 갔더니 완전히 딴 세계가 되어 있었다"
- 플레이어가 자주 가는 세계일수록 인간선택이 강하게 쌓인다

## 5. 1987~88년 — 이야기 재료

> 실제 역사 사건은 **분위기와 배경**으로만 쓰고, 특정 인물·사건을 직접 재현하지 않는 방향 추천.

| 시대 재료 | 게임에서 쓰는 법 |
|---|---|
| 올림픽 준비 | **공사가 올림픽 전에 게이트 문제를 "정리"하려고 콜을 마구 뿌린다** → 콜이 넘쳐나는 시대라는 명분. 메인 스토리의 시한폭탄 |
| 도시 미화, 판자촌 철거 | 철거된 동네가 게이트 부지가 된다. 넝마주이와 연결 |
| 거리의 매캐한 공기 | 동네 사람들이 방독면에 익숙하다 → 3번 세계 독가스가 낯설지 않은 섬뜩함 |
| 보도 통제, 9시 뉴스 | 뉴스는 게이트 사고를 "가스 누출", "지반 침하"로 보도. 진실은 기사식당 소문에 |
| 3저 호황, 아파트 붐 | 공사장마다 게이트가 발견된다는 소문. 땅값과 게이트의 관계 |
| 대선 정국 | 경호 일거리 (유세장), 포스터, 확성기 트럭 — 동네 일상 콜 재료 |
| 마이카 시대 시작 | 티코(공사 차)가 막 퍼지는 중. 차 있는 사람이 콜 기사가 된다 |

### 메인 스토리 뼈대 (초안)
- **1987년 봄**: 플레이어가 티코를 할부로 뽑고 콜 기사로 등록. 첫 동료와 만남
- **1987년 여름~가을**: 콜이 늘어난다. 작은 번호에서 큰 번호로. 넝마주이와 첫 접촉
- **1987년 겨울**: 공사가 "올림픽 전 정리 계획"을 위해 대형 에픽 콜을 연달아 낸다
- **1988년 여름**: 올림픽 개막 직전, 게이트가 우리 세계 쪽으로 열리기 시작한다. 동네에 처음으로 몬스터가 나타남
- **결말 후보**: 우리 세계도 누군가의 N번 세계였다는 것, 넝마주이의 정체, 0번 세계

## 7. 프로토타입 범위 갱신

브레인스톰 #1의 1차 목표를 이렇게 바꾼다.

1. TPS 이동·사격 + 사격 미터기
2. 동네 기본 맵 1개 + **티코** 운전 + 무전 콜
3. **세계 생성기 v0**: 번호 입력 → 갈라진 사건 1개 + 규칙 1~2개 + 변조 레이어 1개
   - 규칙 3종부터: 독가스, 소리 반응, 영원한 밤
4. 몬스터 2종 + 간단한 진화
5. **첫 동료 1명** (고정 캐릭터), 명령 4개 + 기절 전용 명령 2개
6. **기절 → 동료 단독 진행 / 전멸 → 넝마주이 회수 → 기사식당에서 깨어남**
7. 계약금·중도금·잔금 정산 + 회수비
8. 기억 손실 + 단서 1종(카세트) + 사인 도감 첫 칸
