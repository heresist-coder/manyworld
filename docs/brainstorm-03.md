# 매니월드 브레인스톰 #3 — 디멘션 뷰로

> 확정 (D7): 전멸한 기사를 회수하는 세력은 **매니월드의 관리 공무원 조직, 디멘션 뷰로**다.

---

## 1. 한 줄 정의

**"여러 세계를 관리하는 동사무소."**

세계와 세계 사이를 오가며 번호를 매기고, 사고를 처리하고, 쓰러진 사람을 규정대로 수거해 원래 세계로 돌려보내는 공무원들.
초월적인 존재인데 하는 일과 말투는 **1987년 동사무소 민원 창구** 그대로다. 이 어긋남이 이 조직의 맛이다.

> 참고: 게임 〈컨트롤〉의 연방통제국(FBC)과 결이 비슷하다. 차별점은 **한국 80년대 관공서 정서**. 결재판, 도장, 번호표, 먹지, "담당자 자리 비움", 촌지.

---

## 2. 우리 세계 공사와 무엇이 다른가

| | ○○개발공사 (우리 세계) | 디멘션 뷰로 (매니월드) |
|---|---|---|
| 소속 | 우리나라 정부 산하 | 어느 세계에도 속하지 않음 |
| 하는 일 | 게이트 부지 관리, **콜 발주** | 세계 번호 등록, **사고 처리, 회수**, 생태 고시 |
| 태도 | 은폐하고 하청에 떠넘긴다 | 규정대로 처리한다. 감정이 없다 |
| 기사와의 관계 | 돈 주는 쪽 | 뒷수습하는 쪽 |
| 분위기 | 군사정권 공기업의 권위주의 | 끝없이 오래된 관료제의 무심함 |

- **콜은 공사가 내고, 사고는 뷰로가 치운다.**
- 공사 높은 사람들은 뷰로의 존재를 안다. 하지만 뷰로에게 명령할 수는 없다. 공사도 뷰로 앞에서는 민원인일 뿐
- 플레이어 입장에서 공사는 **거래 상대**, 뷰로는 **피할 수 없는 행정**

---

## 3. 세계 번호를 매기는 것도 뷰로다

- 절차 생성 세계 번호(D6)는 **뷰로의 세계 등록 대장 번호**다
- "제47번 세계"라는 표기 자체가 뷰로 공문서 양식
- 콜 정보의 "공사 추정치"는 공사가 뷰로 대장을 불완전하게 베낀 것 → 그래서 틀릴 때가 있다
- 세대 리포트(진화 현황)도 뷰로가 발행하는 **"제○번 세계 생태 현황 고시"**
  - 동사무소 게시판에 붙는 공고문 형식. 딱딱한 문장 속에 섬뜩한 내용
  - 예: `고시 제1987-47-14호 / 제47번 세계 제14세대 / 주요 서식종 평균 외피 두께 12% 증가 / 야간 활동 개체 비율 상승 / 해당 세계 출입 민원인은 유의 바람`

## 4. 회수 절차 — 전멸하면 일어나는 일

### 흐름
```
[전멸]
  ▼
화면 암전. 타자기 소리, 도장 찍는 소리
  ▼
[뷰로 대기실에서 깨어남]
  형광등, 나무 장의자, 번호표를 손에 쥐고 있다
  벽시계, 달력(1987), "민원 처리 순서" 안내판
  ▼
"○○번 민원인, 3번 창구로 오세요"
  ▼
[창구 처리]
  회수 확인서 수령 / 회수 수수료 납부 / 압류 물품 통지
  ▼
[귀가]
  뷰로 문을 나서면 기사식당 뒷골목 (혹은 티코 운전석)
```

### 창구에서 받는 서류
| 서류 | 내용 | 게임 역할 |
|---|---|---|
| **회수 확인서** | 회수 일시, 세계 번호, 발견 위치, 발견 상태 | 사인 단서. 단, **일부 항목이 검은 줄로 가려져 있다** |
| **수수료 고지서** | 회수비, 인지대, 체류 초과 과태료 | 중도금에서 차감. 모자라면 미납 기록 |
| **동일인 확인서** | "본 민원인은 원적 세계 기재 인물과 동일인임을 확인함" + 도장 | 아무 설명 없이 매번 나온다. 떡밥 |

### 회수 비용 구조
- **회수 수수료**: 세계 번호가 클수록, 몸이 깊이 끌려갔을수록 비싸다
- **인지대**: 서류 한 장마다 붙는 소액. 쌓이면 꽤 된다 (블랙코미디)
- **체류 초과 과태료**: 콜 제한 시간을 넘겨 쓰러졌으면 추가
- **장비는 가져가지 않는다 (D10).** 회수 대가는 전부 돈으로 낸다
  - 쓰러진 자리에 떨어뜨린 장비는 회수 확인서의 "현장 잔류 물품" 칸에 적힐 뿐, 뷰로가 챙겨 주지 않는다 → 다음 출동 때 직접 주우러 가야 한다

### 동료 회수
- 동료도 같은 절차로 회수된다. 대기실 옆자리에서 같이 깨어난다
- 동료 몫 수수료도 플레이어가 낸다 (고용주 책임). 안 내면 동료 친밀도 하락
- ~~실종 처리~~ → **보류 (D8)**. 나중에 넣는다. 넣게 되면 뷰로가 `소재 불명 — 수색 보류` 도장을 찍고, 플레이어가 직접 구출 콜로 찾으러 가는 구조

## 5. 기억 손실은 뷰로가 한 일일까

브레인스톰 #2에서 "기절하면 직전 기억이 날아간다"고 정했다. 이걸 뷰로와 묶을 수 있다.

- **표면 설명**: 기절의 충격 때문에 기억이 없다
- **숨은 진실 후보**: 뷰로가 회수할 때 **보안 규정에 따라 기밀 사항을 지운다**
  - 회수 확인서의 검은 줄과 같은 원리. 기억도 서류처럼 "먹칠"된다
  - 그래서 왜 죽었는지 모른다 → **"왜 죽는지도 모르는 세계"의 이유가 행정 처리였다**
- 사인을 밝혀내는 것 = **기밀 해제**
  - 사인 도감에 기록될 때 연출: 검은 줄이 걷히며 원래 문장이 드러난다
  - 단서를 모아 뷰로에 **"정보 공개 청구"**를 넣으면 회수 확인서의 일부 항목을 볼 수 있다 (수수료, 대기 기간, 자격 필요)
- 이 반전은 중후반에 밝힌다. 초반엔 그냥 "기절해서 기억이 없다"로 보이게

## 6. 뷰로와의 관계

### 민원 이력 (평판 수치)
- 수수료를 제때 내고, 규정을 지키면 **모범 민원인** → 처리가 빨라지고, 수수료 감면을 받는다
- 미납, 무허가 장비, 뒷콜 → **요주의 민원인** → 회수 지연(몸이 세계에 오래 방치), 과태료 증가, 대기 번호가 밀린다
- 회수 지연은 실제 손해다: 몸이 오래 방치되면 몬스터에게 끌려가고, 회수비가 오르고, 현장에 남긴 장비가 더 흩어진다

### 담당 공무원 NPC
- **고정 담당자**를 하나 둔다. 예: 3번 창구 **○ 계장**
  - 회색 점퍼, 돋보기안경, 결재판, 커피믹스
  - 무표정하고 규정만 말하지만, 오래 다니면 아주 조금씩 사적인 말을 흘린다
  - "…47번은 요즘 가지 마세요. 이번 달만 서류가 세 건째라." ← 이게 귀한 정보
- 다른 번호 세계에서 **같은 얼굴의 공무원**을 마주친다면? (각 세계에 같은 사람이 같은 일을 하고 있다)

### 촌지 (뇌물)
- 80년대 관공서답게 봉투를 건넬 수 있다
- 효과: 과태료 하나 빼 주기, 대기 순서 당기기, 검은 줄 한 줄 보여 주기
- 위험: 받는 공무원도 있고, 감찰에 걸리는 공무원도 있다 → 걸리면 민원 이력 크게 하락
- 같은 계장이라도 받을 때가 있고 안 받을 때가 있다 (그날 분위기, 감사 기간)

### 뷰로가 내는 일 (뷰로 콜)
- 공사 콜과 다른 종류의 일거리
  - **현장 확인**: 대장에 등록만 된 번호에 들어가서 실제 상태 보고 (조사 위주, 전투 적음)
  - **유실물 회수**: 다른 기사가 쓰러진 자리에 남긴 물건 수거
  - **표지 설치**: 위험 구역에 뷰로 표지판 박기
  - **수색 협조**: 실종 처리된 사람 찾기 (뷰로는 직접 안 찾는다)
- 보상은 적지만 **민원 이력 상승 + 기밀 정보 일부 열람**

---

## 7. 세계 안에서 뷰로를 마주칠 때

- 가끔 세계 안에서 **현장 요원**을 목격한다
  - 회색 우비, 서류 가방, 번호판 없는 검은 관용 세단
  - 몬스터가 그들을 공격하지 않는다. 혹은 그들 근처에 몬스터가 없다
  - 말을 걸면 대답하지 않거나 "민원은 창구에서 접수하세요"
- 뷰로 표지판: 세계 곳곳에 박혀 있는 공고판. 녹슬고, 일부는 몬스터가 부순 상태
  - `제12번 세계 / 소음 금지 구역 / 디멘션 뷰로` ← 규칙 힌트 역할
  - 표지판 내용이 오래되어 지금 생태와 안 맞을 수도 있다 (진화로 낡은 정보)
- 쓰러진 다른 기사를 현장 요원이 **수거하는 장면**을 멀리서 보는 연출 → 플레이어가 처음으로 "회수가 이렇게 일어나는구나" 깨닫는 순간

## 8. 이름과 표기

- 사용자 확정명: **디멘션 뷰로**
- 80년대 사람들 입에서는 그냥 **"뷰로"**, 혹은 **"거기"**, **"그 사무소"**
- 공문서 표기 후보 (선택 사항)
  - 영문 그대로 `DIMENSION BUREAU`, 한글 부기 없음 → 외래어라 더 낯설다. 이 세계 것이 아니라는 신호
  - 혹은 한자 병기 `次元管理局`처럼 보이는데 **한자가 미묘하게 틀린** 표기 → 다른 세계 문자를 흉내 낸 듯한 섬뜩함
- 도장(직인) 디자인이 아트 포인트. 회수 확인서, 고시문, 표지판에 같은 직인

## 9. 스토리 뼈대 갱신 (넝마주이 → 뷰로)

- **1987년 봄**: 첫 전멸. 뷰로 대기실에서 깨어난다. 번호표, 창구, 계장. 정체를 모른 채 수수료를 낸다
- **1987년 여름~가을**: 뷰로 콜을 받기 시작. 세계 안에서 현장 요원을 목격. 회수 확인서의 검은 줄이 신경 쓰인다
- **1987년 겨울**: 정보 공개 청구로 첫 기밀 해제. 기억 손실이 뷰로의 처리였다는 의심
- **1988년 여름**: 올림픽 직전 게이트가 열린다. **공사는 뷰로에 협조를 요청하지만 뷰로는 "관할 외"라며 거절**. 우리 세계는 스스로 막아야 한다
- **결말 후보**
  - 뷰로는 누구의 기관인가? 혹시 번호가 없는 세계(0번)의 것?
  - "동일인 확인서"는 왜 매번 발급되나? 회수될 때마다 원래의 나와 같은 사람이 맞나?
  - 우리 세계도 뷰로 대장의 한 줄일 뿐이라는 것

---

## 10. 프로토타입 반영

브레인스톰 #2의 7장 6번 항목을 이렇게 바꾼다.

- 전멸 → 암전 + 타자기 소리 → **뷰로 대기실에서 깨어남**
- 창구 대화 1회 (고정 담당자 1명)
- 서류 2종: **회수 확인서**(검은 줄 포함) + **수수료 고지서**
- 수수료는 돈으로만 (장비 압류 없음)

## 11. 정할 것

1. 뷰로가 기억을 지운다는 반전을 **정식으로 채택**할지 (채택하면 사인 도감 = 기밀 해제로 연출 통일)
2. 공문서 표기: 영문 그대로 vs 미묘하게 틀린 한자 병기
3. 촌지 시스템을 넣을지 (블랙코미디로 좋지만 톤 조절 필요)
4. 넝마주이는 완전히 버릴지, 고물상·암시장 NPC로 작게 남길지
