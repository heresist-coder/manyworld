# 첫 자연 월드: 숲 현장 (숲속의 빈 방)

2026-10-12. D21–D23. 목표 샷: [03 숲속의 빈 방](art/2026-10-12/selected-scenes-v3/03-empty-forest-room-dolls.png) (샷 속 마네킹은 곰인형으로 읽는다).

## 흐름 (D18)

1. 남서쪽 초원 흙길, 티코 옆에서 시작한다. 무전: "숲속 공터 의자에 곰인형이 하나 있을 겁니다. 그것만 가져오세요."
2. 흙길 약 300m를 몰아 숲 가장자리 주차 공터에 세운다.
3. 숲길 80m를 걸어 들어가면 빈 방이 나온다.
4. 의자 위 곰인형을 집는다(E 길게). 방이 깨어난다.
5. 차로 돌아와 타면 콜 대기. 8초 뒤 "띠리릭─ 다음 콜" → [Y] 받으면 같은 숲을 새로 짓는다 (현장이 아직 하나뿐).

정산·뷰로·세계 번호는 이 흐름에 없다. 둘 다 쓰러지면 티코 옆에서 다시 시작한다.

## 빈 방

| 부분 | 내용 |
|---|---|
| 방 | 15×15m 주황빛 짙은 흙에 솔잎 섞인 바닥, 벽 밑에 풀. 소나무가 세 면에 두 줄로 곧게 서서 벽을 만든다. 열린 한 면이 숲길을 본다 |
| 의자 | 가운데, 들어오는 사람을 본다 (Town DiningChair_01). 그 위에 작은 곰인형 (Apocalypse Toy_Bear_01) |
| 곰인형 여섯 | 아이 키만 한(0.95~1.1m) 밝은 곰인형. 벽 밑에 기대 앉아 의자를 본다 (Horror Carnival Plushie 04 곰 넷, 03 토끼·07 원숭이) |

## 규칙

- **곰인형은 아무도 보지 않을 때만 움직인다.** 기사 화면에 보이거나 은주 시야(55°, 40m, 가리는 것 없음)에 들면 멈춘다. 은주를 "대기"로 세워 두면 그쪽을 지킨다.
- 곰인형을 집기 전: 2~4초마다 한 걸음씩 의자 쪽으로 모인다. 움직일 때 부드러운 툭 소리가 난다.
- 곰인형을 집은 뒤: 1초 남짓마다 사람 쪽으로 온다. 발밑에 닿으면 체력 -14. 2.5초 뒤 열린 면에서 소나무가 7초에 걸쳐 솟는다.
- 닫힌 방에 갇히면 인형을 전부 쓰러뜨려야(총·쇠파이프, 인형당 체력 40) 벽이 가라앉는다. 총소리는 숲의 몬스터를 부른다.
- 숲에는 기는 놈 5, 덩치 2가 있다 (방에서 45~200m).

## 월드

| 항목 | 내용 |
|---|---|
| 크기 | 768m. 가장자리 170m는 높은 산(통행 불가). 그 너머 먼 산은 능선 띠 두 겹(1.5km 짙은 푸른색, 2km 옅은 색). 정점색 셰이더(`Shaders/Backdrop.shader`)라 안개에 묻히지 않고 공기 원근 색을 그대로 낸다 |
| 지형 질감 | 직접 만든 256px 이음매 없는 질감 7종 (`NatureKit.Layer`): 풀잎 붓질이 든 올리브 초원·짙은 풀 얼룩·마른 풀, 솔잎 흩어진 숲 바닥, 자갈 박힌 황토 흙길, 바퀴 자국·길 가장자리의 짙은 흙, 바위. 기운 숲 바닥은 모래흙이 드러난다 |
| 숲 | 소나무 위주 터레인 나무 약 1만 1천 그루. 남서쪽 초원엔 둥근 나무가 드문드문. 가장자리는 짙은 소나무 |
| 오는 길 (목표 샷 01) | 깨끗한 노란 해치백(Synty Military SM_Veh_Car_Small_01, 진흙 얼룩을 지운 텍스처 사본 `ArtSetup.CleanCar`, 트리포 불필요). 출발점 오른쪽 전경에 둥근 바위 무더기와 키 큰 풀, 넓은 흙길, 한쪽 통나무 울타리, 둥근 바위·잔돌, 떠 있는 집(19m 위에서 천천히 흔들림), 길을 건너는 구름 그림자 |
| 숲길 (목표 샷 02) | 주차 공터 → 방 입구. 양옆 소나무가 길 쪽(조금은 방 쪽)으로 16~24° 기울어 V자로 모인다. 숲 바닥 대신 볕 드는 풀밭 |
| 풀 | **Stylized Grass Shader for Unity 6** (Staggart Creations, 유료, `Packages/xyz.staggart-creations.stylized-grass`, 깃 제외: 공개 저장소에 올리면 DMCA)를 쓴다. GrassPatch·Thick·Tall·Thin·토끼풀·캐모마일 LOD0 메시와, ThirdParty/Generated에 만든 머티리얼 사본(인스턴싱, 잎끝 올리브색, 역광 0.45)을 `GrassField`가 GPU 인스턴싱으로 약 5만 포기 그린다. 지형 레이어 색 × 알파맵으로 만든 512px 컬러맵을 전역 `_ColorMap`으로 넘겨 풀 밑동이 땅 색을 따른다. 패키지가 없으면 직접 만든 풀 셰이더(`Shaders/Grass.shader`)로 대체한다 |
| 바위 | 직접 만든 각진 로우폴리 바위 8종 (`NatureKit.Boulder`: 쪼갠 정이십면체, 면마다 법선). 길 어깨·숲 가장자리·방 입구 양옆, 잔돌 약 400개 |
| 구름 | 카메라를 감싸는 구름 돔 셰이더 (`Shaders/CloudDome.shader`): fbm 뭉게구름, 해 쪽 샘플로 아래 그늘, 지평선은 대기색 |
| 빛 | 늦은 오후 해(따뜻함, 22°) + 푸른 그늘, 선형 거리 안개 50~1350m로 먼 산이 푸르게 물러난다 |
| 간접광 (D25) | 같은 시드의 숲에 APV를 구운 빛 데이터 씬 `Scenes/ForestLighting.unity`를 현장에 있는 동안 덧붙여 연다 (`ForestLighting`). 그늘이 흙·나무에서 튕긴 따뜻한 빛으로 찬다. 굽기: Manyworld > Field > Bake Forest Lighting (약 35초, 데이터는 깃 제외). 하늘 가림 굽기는 6000.3.22f1의 D3D12 레이트레이싱에서 에디터가 죽어 끔 |
| 회화풍 후처리 (D25) | 일반화 쿠와하라 필터(`Shaders/Painterly.shader`, PC 렌더러의 전체 화면 패스). 숲 현장에서만, F9로 끄고 켬 |
| 그림자·후처리 | 그림자 520m·4096·캐스케이드 4, SSAO, ACES + 스플릿 토닝 + 그늘 살짝 들기(Shadows/Midtones/Highlights), 약한 블룸 |
| 먼 숲이 하얗게 보이던 문제 | 잎 텍스처의 투명 칸이 밝은 회색이라 먼 밉맵에서 번졌다. 투명 칸을 잎 평균색으로 채운 사본을 생성해 쓴다 (`ArtSetup.FilledLeafTexture`) |
| 소리 | 숲 환경음, 곰인형 걸음, 나무 솟는 소리 (Agent Audio) |
| 생성 시간 | 약 2.5초 (로그에 단계별 시간) |
